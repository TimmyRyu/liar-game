# 라이어 게임 (워크숍용)

접속 주소: https://timmyryu.github.io/liar-game/

1. 처음에 자기 자리 번호(1~7)를 한 번 고릅니다.
2. 판마다 사회자가 팀별 4자리 코드를 불러 줍니다. 코드를 넣으면 시민은 제시어를, 라이어 1명은 "당신은 라이어"를 봅니다.

- 2팀 x 8판, 코드는 16개이고 사회자 코드표에만 있습니다(이 저장소에는 없음).
- 카드 내용은 그 판의 코드로 암호화되어 있어 코드 없이는 열리지 않습니다.
- 1~7판은 7명이 한 번씩 라이어가 되고, 8판은 7판 라이어를 뺀 6명 중에서 정해집니다.
