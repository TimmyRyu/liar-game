# 라이어 게임 (워크숍용)

접속 주소: https://timmyryu.github.io/liar-game/

1. 처음에 사회자가 알려 준 우리 팀 인원(3~12명)과 자기 자리 번호를 고릅니다.
2. 판마다 사회자가 코드표에서 우리 팀 코드를 하나 골라 불러 줍니다. 코드를 넣으면 시민은 제시어를, 라이어 1명은 "당신은 라이어"를 봅니다.

- 라이어는 고른 인원 안에서만 나오고, 인원마다 24개 코드에 고르게 나뉘어 있습니다.
- 코드는 팀당 24개, 총 48개이고 사회자 코드표에만 있습니다(이 저장소에는 없음).
- 카드 내용은 그 코드로 암호화되어 있어 코드 없이는 열리지 않습니다.
