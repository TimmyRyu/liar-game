# 라이어 게임 (워크숍용)

접속 주소: https://timmyryu.github.io/liar-game/

1. 시작할 때 사회자가 4자리 게임 번호를 알려 줍니다. 모두 입력하고, 화면에 뜬 확인 단어가 같은지 맞춰 봅니다.
2. 각자 자리 번호(1~7)를 고릅니다.
3. 판마다 판 번호와 우리 조(a 또는 b, 대소문자 무관)를 넣으면 카드가 나옵니다.

- 같은 게임 번호면 어느 휴대폰에서든 같은 결과가 나오고, 번호가 바뀌면 라이어 순서와 제시어가 새로 정해집니다.
- 판마다 라이어 1명, 6판 동안 같은 사람이 두 번 라이어가 되지 않습니다.
